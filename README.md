# formalizing-groth16
A partial formalization of ZoKrates’ smart contract implementation of the Groth16 zero-knowledge proof scheme.

## Overview
Specifically, this is a formalization of the "verify" method within ZoKrates' Groth16 smart contract. This formalization uses the University of Exeter's Isabelle/Solidity shallow embedding framework compatible with Isabelle2025-2. 

* ZoKrates' original smart contract - zokrates_proof_systems/src/scheme/groth16.rs 
* Isabelle/Solidity - https://isa-afp.org/entries/Isabelle-Solidity.html
